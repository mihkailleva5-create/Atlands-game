# Своя музыка

В игре уже есть 8 встроенных треков — они синтезируются WebAudio
прямо в браузере (js/music.js), файлы не нужны.

Чтобы добавить свой mp3/ogg:

1. Положи файл сюда, например `assets/music/my-track.mp3`
   (только музыка, на которую у тебя есть права).
2. Открой `js/music.js` и добавь в `EXTERNAL_TRACKS`:

```js
const EXTERNAL_TRACKS = [
  { title: 'Мой трек', emoji: '🎵', desc: 'Любимая мелодия', file: 'assets/music/my-track.mp3' },
];
```

3. Обнови страницу — трек появится во вкладке «🎵 Музыка».
