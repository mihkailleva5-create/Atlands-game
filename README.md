# 🏝️ Atlands — уютная игра для Telegram

Милая мини-игра (Telegram Mini App): твой остров, питомцы, искры,
задания и музыка. Работает из одного `index.html` — без сборки.

## Что уже есть (база)

**Игра**
- Тап по питомцу → искры ✨, опыт, сердечки; пассивный доход от украшений острова
- 3 стата питомца (настроение / сытость / бодрость) влияют на доход; уход: покормить, поиграть, погладить
- Магазин: 6 украшений острова + лакомства за капли 💧 (в т.ч. буст дохода x2)
- Уровни, эволюция острова (5 стадий), ежедневная награда, 3 задания дня, офлайн-доход (до 8 часов)

**Модельки** (`js/models.js`)
- 6 анимированных SVG-питомцев: аксолотль Лотти, облачный кролик Моти, черепашка Пуф,
  птичка Киви, осьминожка Блоб, лунная кошечка Мими
- Моргание, дыхание, покачивание, прыжок при тапе; скины-расцветки и аксессуары (цветок, бант, звезда, корона)
- SVG = чётко на любом экране, почти нулевой вес, легко добавлять своих:
  новая запись в `PETS` + функция в `RENDERERS`

**Музыка** (`js/music.js`)
- 8 встроенных треков (утро, океан, лес, закат, ночь, дождь, светлячки, праздник) —
  синтезируются WebAudio, файлов и авторских прав не нужно, плейлист во вкладке «🎵 Музыка»
- Свои mp3: папка `assets/music/` + строка в `EXTERNAL_TRACKS` (см. assets/music/README.md)
- Звуковые эффекты: тап, монетки, покупки, левел-ап

**Сохранения** (`js/save.js`)
- Telegram CloudStorage (облако, сейв режется на чанки под лимит 4096) + зеркало в localStorage
- Автосейв: локально сразу, в облако — при паузе/закрытии и каждые 30 сек; статус «☁️ Сохранено» в шапке
- Экспорт/импорт JSON-файлом, сброс, версии сейва и миграции (`SAVE_VERSION`)

**Telegram** (`js/telegram.js`, `bot/`)
- WebApp: ready/expand, тема, HapticFeedback, MainButton для ежедневной награды, BackButton,
  автосейв при сворачивании, отправка прогресса боту через `sendData`
- Готовый бот на Python: `bot/bot.py` (кнопка игры, приём прогресса в SQLite, /profile)

## Запуск

Просто открой игру по https (нужен сервер из-за ES-скриптов и CloudStorage):

```bash
# локально для разработки
python3 -m http.server 8080
# -> http://localhost:8080
```

Продакшен: включи GitHub Pages (Settings → Pages → main / root) —
игра будет на `https://<логин>.github.io/Atlands-game/`.

## Подключение бота

1. Создай бота у [@BotFather](https://t.me/BotFather), получи токен.
2. Опубликуй игру на https (например GitHub Pages).
3. Запусти бота:

```bash
cd bot
pip install -r requirements.txt
BOT_TOKEN=токен_от_BotFather WEBAPP_URL=https://<логин>.github.io/Atlands-game/ python bot.py
```

4. У бота: `/start` → кнопка «Играть». В @BotFather командой `/newapp`
   или `/setmenubutton` можно повесить игру на кнопку меню.

## Структура

```
index.html        — вход, разметка экранов
css/style.css     — милый пастельный интерфейс, анимации моделей
js/models.js      — SVG-модели питомцев, украшения, стадии острова
js/music.js       — музыкальный движок (8 треков WebAudio + свои mp3) и SFX
js/telegram.js    — Telegram WebApp: тема, вибро, MainButton, sendData
js/save.js        — CloudStorage + localStorage, чанки, миграции, экспорт/импорт
js/game.js        — состояние, экономика, магазин, задания, UI
bot/bot.py        — пример бота (WebApp-кнопка + SQLite-прогресс)
assets/music/     — сюда класть свои mp3
```

## Куда развивать дальше

- Новые питомцы и скины в `js/models.js`, новые треки — одна запись в `SYNTH_TRACKS`
- Мини-игры за капли, друзья/рейтинг через бота, магазин за Telegram Stars
- Серверная проверка `initData` (HMAC по токену бота), если появятся награды за Stars
